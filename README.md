# 📚 NF16 – Algorithmique et structures de données en C

Ce dépôt regroupe les codes réalisés dans le cadre de l'UV **NF16** à l'UTC, dédiée à l'**algorithmique et aux structures de données** en langage C.

Les sujets des TD et TP sont fournis au format **PDF** dans le dossier [`Sujets/`](Sujets/) et peuvent être ouverts directement depuis le dépôt.

<br/>

## 📌 Vue d'ensemble

### Travaux dirigés

| TD | Thème principal | Dossier |
|----|----------------|---------|
| TD1 | Premiers programmes en C : variables, entrées/sorties, exercices d'introduction | [`TD/TD1/`](TD/TD1/) |
| TD2 | Fonctions, pointeurs, tableaux et chaînes de caractères (`swap`, `my_strlen`…) | [`TD/TD2/`](TD/TD2/) |
| TD3 | Structures et types personnalisés | [`TD/TD3/`](TD/TD3/) |
| TD4 | Listes chaînées : construction et manipulation | [`TD/TD4/`](TD/TD4/) |
| TD5 | Complexité algorithmique (analyse en O) | [`TD/TD5/`](TD/TD5/) |
| TD6 | Piles et files (pseudo-code) | [`TD/TD6/`](TD/TD6/) |

> Les sujets de TD1 à TD12 sont disponibles dans [`Sujets/Sujets_TD/`](Sujets/Sujets_TD/) ; les TD sans dossier de code ont été traités sur papier.
